## Design references (not copied distributions)

- Speech-Bubble-Layer: object layers and ComfyUI editor entry point.
- Speech-Bubble-Comic-Editor-App / Forge Neo: nondestructive image additions and editing interactions.
- ComfyUI-H3-Continuum-EZ: single-modal entry point and separate text/image execution.
- MossImage-BBOX-Prompter: reject stale asynchronous UI results.
- CreativeField and OpenGPEX: crop/edit/composite and candidate concepts only. Their GPL source, assets and application distributions are not included.

The P-H3 API graph was independently assembled from the user's provided workflow and inspected standard ComfyUI node interfaces. No model implementation is copied. Internal node wrappers only read assets and capture results around standard ComfyUI nodes.

## External software and weights

The package runs within ComfyUI and uses its already-installed PyTorch, NumPy, Pillow and aiohttp. Their licenses are not changed by this package. ONNX Runtime is an optional, preinstalled integration for the supported local ISNet model. No third-party Python runtime, model weight, browser binary, JavaScript framework, or font is bundled.

MiniMax H3/P-H3 and ISNet weights retain the terms of their respective distributors. The repository owner's ownership of this code does not remove model, font or imported-image usage conditions.

## Included presets

Included SFX are editable text; included symbols, lines and frames are procedural shapes; two bubble body paths come from the MIT source listed above, with the others generated by this package. This is not a redistribution of the legacy editor's complete raster asset catalogue. No font files are included.


## Local editor port (editor.1, 2026-11-07)

This section supersedes the limited RC3 port description above. The same MIT source at
`83109b21beb7af0926db8a9f02a7bb27eae3c87d` supplies:

- `web/source-bubbles.mjs`: procedural curves, SVG anchors, tail/body union mask,
  outline dilation and double outlines from `web/speech-bubble-editor.html`.
  The oval follows the source application's procedural path, which deliberately
  skips its older asymmetric oval SVG.
- `web/source-text.mjs`: tracking and vertical grapheme rendering, punctuation
  orientation, column order, underlines and strike-through from the same file.
- `web/source-speed.mjs`: normalized emphasis-ray geometry from that file.
- `web/render.mjs`: the original frame border compositing branch.
- `font_catalog.py`: identical copy of `speech_bubble_editor/font_catalog.py`.
  Local font files are served by catalogue ID and are not packaged or exported.
- `web/source-assets/`: 328 original SFX/stamp PNG/WebP files and one sticky-note
  WebP. Japanese/English labels are taken from `web/asset-labels.js`.

Host adapters, portable storage and editor UI integration are local adaptations.
