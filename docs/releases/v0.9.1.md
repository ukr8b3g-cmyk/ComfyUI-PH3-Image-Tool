# PH3 Image Tool v0.9.1

部分生成で、生成された被写体を保ちながら周囲の色ズレを抑えます。キャンバスの選択範囲は点線で表示され、選択中も画像の色をそのまま確認できます。

- **画像生成**　P-H3 ImageとMiniMax-H3-Imageに対応。生成範囲は初期値の「自動」で新規・画像全体・選択範囲を判定します。MiniMax-H3-ImageのAI文も同じ範囲に合わせます。
- **編集**　投げ縄とAIブラシを上段に配置。選択しても生成タブを維持し、レイヤーは初回にフローティングで表示します。画像・ペイントレイヤーに消しゴムを使えます。
- **背景**　最下段で表示切替できるキャンバス背景を追加しました。透過、単色、グラデーション、網点、平行線、市松を選べます。
- **安定性**　拡大後の参照画像が上限を超えるとキュー登録前に案内します。画像キャッシュを制限し、保存・読み込みや非同期処理の回帰を修正しました。

P-H3 ImageはComfyUI v0.44.0以上、MiniMax-H3-Imageはv0.45.0以上が必要です。作品とワークフローを保存し、ZIP内のフォルダーを同じ `custom_nodes` の位置へ更新してください。作品データは `user/default/ph3_image_tool` にあります。更新後はComfyUIを再起動し、ブラウザーで Ctrl＋F5 を押してください。

ローカルのPython 169件、Node.js 214件、隔離Chromeの選択とパネル操作8項目を確認しました。既存のMiniMax-H3-Image生成結果を再合成した試験では、測定した背景の平均RGB差が約95％減り、リンゴの赤と選択範囲外の画素を保持しました。色補正の検証には保存済みの生成結果を使用しています。

## English

Selection edits now match unchanged surrounding colors when the source crop provides a reliable reference. The dotted selection outline leaves the canvas colors visible. This release also adds automatic generation scope, scope-aware MiniMax-H3-Image prompt enhancement, editable canvas backgrounds, a layer eraser, and a default floating Layers panel. Large native references are checked before queueing, and the decoded image cache is bounded.

Use ComfyUI v0.44.0 or later for P-H3 Image and v0.45.0 or later for MiniMax-H3-Image. Update the inner ZIP folder, keep your project data, restart ComfyUI, and hard-refresh the browser.
