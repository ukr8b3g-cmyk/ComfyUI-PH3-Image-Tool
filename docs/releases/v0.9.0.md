# PH3 Image Tool v0.9.0

1枚画像のP-H3生成と、文字・吹き出し・画像のレイヤー編集をまとめた公開版です。

- T2I/全体/部分編集、共通のステップ数・進捗率・停止、生成中の編集と既存レイヤーの保持。
- AI効果文字のT2I/参照、ポップ/キュート/ファンシー、縦横、色/グラデーション。空の吹き出しと元文字を合成。
- スタンプ110点、ローカルフォントの書体別一覧、集中線、フレーム。
- 色相/彩度、B/C、トーンカーブ、選択内の塗り/透明化/コピー、透明ペイントと調整の再編集。
- P-H3/CPU漫画フィルターと4レイヤー分離、Auto/ISNet背景削除と手動補正。
- WebP品質80の自動保存、設定先頭の保存先選択、PNG/WebP/JPEGと再編集用プロジェクト。
- 自動言語追従、分離パネル、4色の重要操作、ブラシ円/HUDとショートカット、重複Closeの整理。表示回転は左側から上部バーへ移動。

## 更新

作品とワークフローを保存し、ZIP内の`ComfyUI-PH3-Image-Tool`を同じcustom_nodes位置へ更新。`user/default/ph3_image_tool`は削除しないでください。ComfyUIを再起動しCtrl+F5。ノードID・入出力・作品形式は保持しています。

モデル/フォント/利用者作品は同梱しません。ISNetは利用者の確認後に取得します。Manager/Registry登録はこのリリースに含みません。

## 検証

Windowsのローカル環境でJavaScript 178件、Python 144件の回帰検証と、Manifest/ZIP内容・チェックサム照合を実施しました。CIでも同じ検証を実行し、成功後に公開します。保存/再読込、Undo/Redo、元データと透過の保持を含みます。

最新のUI変更の実画面操作はChrome操作ツールの接続障害により未確認です。今回、新しい実P-H3 GPU生成・ISNet推論・ComfyUI再起動による全体受入確認は行っていません。以前の実Chrome/GPU検証は[別記録](https://github.com/ukr8b3g-cmyk/ComfyUI-PH3-Image-Tool/blob/v0.9.0/docs/PRESERVED_LETTERING_VALIDATION_JA.md)です。

4コマ対応は将来の検討事項です。仕様・時期は未確定で、v0.9.0の機能には含みません。
