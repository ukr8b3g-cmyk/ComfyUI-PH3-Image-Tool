# 元文字を保持する吹き出し合成 — 2026-11-08

生成済みのAI効果文字を選び、トゲ吹き出し/思考吹き出しを追加する場合、元文字をモデルへ送らず、空の吹き出しだけをP-H3で生成する。枠内のAI描画を除去し、透過処理済みの元文字を拡縮せず合成する。余白は枠側の拡大で確保。元文字、生成枠、合成結果を別資産として保持する。初期T2I・参照オフは維持する。

## 実GPUの確認

同じSeed42/43/44の前回T2I画像を使い、横書き3件と縦書き3件でトゲ吹き出しを生成・合成した。各3/3で以下を確認。

- ビクッ!! の濁点2画が本体から分離し、感嘆符2個を保持。
- 合成画像の文字領域が、透過処理済み元文字を白地に重ねた画像と全画素一致。文字の拡縮/AI再描画なし。
- 元文字/装飾とも端切れなし。外側はalpha0、吹き出し内部は白/alpha255。
- 標準ComfyUI APIグラフのモデル入力に参照画像/対象文字がないことを確認。

FL2VA INT8、標準P-H3 Image LoRA1.0、er_sde8steps。横書き枠1280×768、縦書き枠はmaterial_size()の指定に従う。合成結果のサイズは元文字/枠の形状で異なる。

Python126件、JavaScript99件成功。この6件の実GPU検証は標準APIと本番の合成関数で確認した。後述の実エディター受入確認とはSeedと検証経路を区別する。閉じていない枠、端切れ、内部余白不足、過大な画像はエラーにする。今回の6例の成功が全Seedの枠品質を保証するものではない。

作品保存後にComfyUIを再起動し、Ctrl+F5で再読込する。モデル/フォント/依存関係の追加ダウンロードはない。
