# 検証記録 — 0.2.0-rc3

確認日: 2026-11-07。対象: この配布ZIPのソース。GitHub上の公開コミットではありません。

## 基準と利用者の報告

利用者から、前版 `0.1.1-rc2` を添付の `PH3_Image_Tool.json` で動作確認したとの報告がありました。本版はそのrc2 ZIPから作成しました。利用者の報告を、本版で開発側がP-H3推論を実行した事実として扱いません。

`generation.py`、`nodes.py`、`storage.py`、`runtime.py`、`web/extension.js` は基準ZIPとのバイト一致を確認しています。`PH3ImageTool` のノードID、出力順、保存形式1、作品ID/リビジョンの入力を維持します。生成APIグラフ作成・結果取得・ComfyUI出力処理を新方式へ置き換える変更はありません。

添付ワークフローは解析して構成を照合しましたが、利用者の作品IDや絶対出力先をサンプルへ転記・同梱していません。後段のSaveWebPMeta設定も変更しません。

## 追加操作で確認した具体例

- マウスホイールによるカーソル中心ズーム、中ボタン/Space移動、Altホイールによる表示回転の前後で、ドキュメントの内容が変化しない。
- 表示を30度回転して選択した矩形が、原寸画像の意図した座標へ2px以内で対応する。
- 角・辺のハンドルが反対側の基準点を保ち、レイヤー回転が表示回転と独立する。
- DeleteとCtrl+Z、およびChromiumに配信されたマウス戻る/進むイベントがUndo/Redoとして動く。文字入力欄のDeleteではレイヤーを消さない。
- 720×480の元画像を360×240/17度回転で配置していても、漫画変換は720×480の原寸結果を保存し、位置/倍率/角度と非表示の原画像を保持する。
- 背景削除のクリックがプレビューの余白を考慮し、背景画素を透明にする一方、中央の対象を保持する。
- PNGの透明画素、可逆WebPとPNGのRGBA画素一致、JPEG品質70/白下地の実ファイルを検証する。
- 書き出し中のモーダル取消、保存・再開、1000×760画面の収まりを確認する。

## 試験の方法と限界

PythonのAPI試験はaiohttpテストサーバーを使用し、ノード試験は実クラスへテスト用保存先を与えています。ComfyUI全体を起動した試験ではありません。

Chromiumはネットワークへ移動しない隔離ページに実編集モジュールを読み込み、Python側の実ストレージ・CPU処理・Pillowエンコードを呼び出しました。漫画変換とフチ補正のBlob Workerも実行しています。ComfyUIのモデル一覧・キュー・画像生成応答・AI文章応答だけはテスト用の模擬です。localStorageもメモリー内の試験用実装です。

これは実ホストのURL/CSP、ComfyUI認証、実ブラウザーの永続ストレージ、Windowsフォント/IME、マウスドライバーの割当を確認したことにはなりません。背景削除のISNet推論は未実施です。

画面画像はテスト用図形です。`generation-simulated.png` は模擬生成結果を含みます。P-H3の画質、精度、速度を示す見本ではありません。

## 修正した重要な問題

- 表示の拡大・回転と、作品/選択の座標変換を分離。
- 画像処理が配置後の縮小サイズで確定されないよう、原画像解像度で適用。
- 背景色クリックがobject-fitの余白でずれる問題を修正。
- 書き出し画面を初期化中に閉じた場合の遅延応答を無効化。
- 保存した漫画プリセットと表示中の選択を一致させる。
- ドラッグ途中のUndoはその操作を取り消し、未確定状態を履歴へ混在させない。
