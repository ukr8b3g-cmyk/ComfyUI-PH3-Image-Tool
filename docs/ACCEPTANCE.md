# rc3の実環境受入チェック

rc2については利用者から添付ワークフローでの動作確認報告がありました。この一覧はrc3について実環境で確認する項目で、今回の開発側では未実施です。隔離CPU/ブラウザーの結果とは区別します。既存の作品をバックアップし、別のテスト作品で確認します。

1. **起動と通常編集**: 対象Windows/ComfyUIで4ノードが登録される。ノードのボタンで画面が開く。日本語IME、フォント、コピー、ショートカットがホストに誤伝播しない。
2. **上流画像**: LoadImageと画像加工ノードの両方を経由し、実際の出力テンソルの先頭画像が取り込まれる。古いLoadImageの原画へ勝手に戻らない。
3. **P-H3新規**: 適切なP-H3モデル構成で小さめの1候補を生成。標準キューの失敗・進捗・結果が正しい。モデルロード時間、ピークVRAM、総時間を記録する。
4. **画像全体編集**: 衣装などを変更し、結果が別レイヤーに残る。元画像・文字・吹き出しが維持される。
5. **リンゴの部分生成**: 手のひら、リンゴの空間と必要な影を選択。原文、seed、モデル名、解像度を記録。顔や服の非選択画素が合成前後で一致することと、指・影・境界の品質を別々に確認する。
6. **座標**: 縦長、横長、端の選択、小さい選択、拡大縮小・回転済み画像、透明画像で切り出しと戻し先を確認する。
7. **競合**: 生成中の文字修正、選択変更、Undo、作品切替、ノード削除、エディター再読込で古い結果が上書きされない。候補は回収できる。
8. **保存**: 採用→保存・適用→ComfyUIワークフロー保存→再起動で同じ作品を復元。`.ph3tool`を新規作品へ読み込み、画像・マスク・文字・参照を確認する。
9. **後段出力**: 保存済みRGB、alpha（白=不透明）、selectionが正しい。保存後の未採用/未保存変更を後段の確定出力と混同しない。
10. **背景削除**: 色指定と選択切り抜きを確認。既に許可・導入済みのISNet/ONNXがある場合だけAI切り抜きを追加確認。モデルの未導入をエラーと表示し、勝手にダウンロードしない。
11. **文章補助**: Generate AIで原文を維持しAI欄だけを更新、画像生成は別操作。元の文を編集した後に古い補助結果が自動採用されない。
12. **終了と取消**: 未保存確認、下書き復元、待機ジョブ取消を確認。他のComfyUIジョブを停止しない。

13. **新UI**: ホイール拡大縮小、Space/中ボタン移動、R/Altホイール表示回転、回転中の選択位置、DeleteとCtrl+Z。マウスサイドボタンはドライバー/ブラウザーの割当を含めて確認する。
14. **画像処理**: 原寸の漫画変換・背景切り抜き・白フチ補正を比較し、原画像保持を確認。CSP設定があるホストではBlob Workerが許可されるか確認する。
15. **書き出し**: PNG圧縮、JPEG/WebP品質、可逆WebP、透過維持と下地合成。通常のComfyUI後段保存設定は別のままであること。

正式安定版やGPU動作保証は、実際に実施した条件に限定して判断してください。
