# 選択部分のコピー・貼り付け

画像レイヤーを選び、矩形・楕円・投げ縄等で範囲を選択します。

- **Ctrl+C → Ctrl+V**：選択部分だけを新しい画像レイヤーへ貼り付けます。同じ作品では元の位置に配置し、範囲を解除して移動ツールへ切り替えます。すぐドラッグ・矢印キーで動かせます。
- **Ctrl+J**：選択部分を複製します。Clipboardは変えません。範囲なしではレイヤー全体を複製します。
- **Ctrl+X → Ctrl+V**：元画像を上書きせず、マスクで選択部分を透明にして貼り付けます。CutとPasteは別々にUndoできます。
- **Ctrl+Shift+C**：表示中の合成をコピーします。通常Copyは現在のレイヤーの画素とマスクを使い、レイヤー不透明度を焼き込みません。
- **編集 / Edit**：コピー・切り取り・貼り付け・選択部分の複製を同じコマンドから実行できます。ブラウザーのOS Clipboardが使えない環境でも、アプリ内のコピーはこのメニューから貼り付けできます。

文字欄・IMEの編集中は文字のコピー/貼り付けが優先されます。ロック中の画像はコピーできますが、切り取りはできません。コピー/PNG準備/画像保存に失敗した場合は元を消しません。透明部分しか選んでいない場合は新規レイヤーを作りません。

外部画像をブラウザーへPasteした場合は、その新しい画像を優先します。ブラウザーのClipboard APIには接続方式・権限による制約があります。サーバー側のOS Clipboardを操作する仕組みは使っていません。

## 左ツール

左ツールは、利用者の指定に合わせて変更前の文字付きボタンへ戻しました。選択設定・解除・反転も元の左パネル内に表示します。アイコンだけの小型表示は採用していません。部分コピー・貼り付けとUndo/Redoの機能修正は維持しています。

これは基本編集の優先実装です。階層フォルダー、追加の7合成モード、画像効果の固定スロット、複数調整を保持する新recipe形式は今回の優先実装に含まれていません。既存の調整・マスク・ペイント・保存形式は維持しています。
