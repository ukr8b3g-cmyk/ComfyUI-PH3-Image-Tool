# v0.9.0 操作ガイド

## 保存と生成
設定で導入済みモデルを確認してから生成します。メインの生成はT2I/全体/部分編集。PH3漫画とAI効果文字は専用画面で候補を確認して「新しいレイヤーとして適用」。進捗/停止は上部の共通バー、履歴は手動で開きます。「編集へ戻る」で生成中も編集でき、結果は新規レイヤーへ追加します。

自動保存先は設定先頭で指定。自動保存は生成候補、画像書出しは編集キャンバス、プロジェクト書出しは画像と編集状態です。ノード反映後の外側Save Imageも別操作です。

## 選択と調整
矩形/楕円/投げ縄/自動選択/色から選択/Bの選択ブラシで範囲を作ります。Shiftは追加、Altは除外、Shift+Altは共通部分。プロパティ上部で対象画像と、色変更/塗り/透明化/コピー/部分生成/効果文字配置を選びます。H/S・B/C・RGB/各色カーブはライブプレビューし、適用で元データ付きレイヤーへ保存。「調整を編集」から再調整できます。

## 描画と移動
- P: 描画ブラシ。サイズ・硬さ・不透明度・描画色を設定。選択範囲があれば内側に描画。
- [ / ]: 描画サイズ、Shift+[ / Shift+]: 硬さ。右ドラッグ（Alt+右も可）は左右でサイズ、上下で硬さ。Escでサイズ調整を取り消し。
- B/E: 選択範囲を塗る/削るブラシ。画像を描くPとは別です。
- V: 移動/変形、H/Space+ドラッグ/中ドラッグ: 表示移動、Rまたは上部「表示回転」: ドラッグで表示回転、Alt+ホイール: 表示回転、0: 表示リセット。
- Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y: Undo/Redo。適用や1ストロークは1回の履歴です。
- Delete: 範囲があれば対象画像の部分透明化、範囲がなければ選択レイヤー削除。文字入力中は横取りしません。

## パネル・再開
生成/プロパティ/レイヤー/履歴は独立したタブ。パネルを分離して移動・サイズ変更でき、元の位置へ戻せます。閉じるは右上に1個。前回の下書きがあれば「新規で開く」「編集を再開」を選びます。新規でも旧下書きは残ります。詳細ショートカットは画面上部の操作ガイドを参照してください。

## ボタンが灰色の場合

使えない操作は無効になり、マウスオーバーで理由が出ます。対象レイヤー、選択範囲、ロック、前面/背面の端、レイヤー/参照の上限などを確認してください。[有効条件の一覧](COMMAND_AVAILABILITY_JA.md)。

「選択→マスク」は選択外を隠します。コピー/貼り付けで既に透明になった画像に同じ選択を適用しても、見た目は変わりません。マスクがない画像では「マスク解除」は使えません。[選択部分のコピー・貼り付け](PIXEL_CLIPBOARD_JA.md)も参照してください。
