# v0.9.0監査の修正と検証（main）

2026-11-10。基準コミットは `0f6c9fbebbf83cffdb3a58c75d6d2063c4973108`。
提供された監査ZIPは証拠として確認し、インストール用差分としては使用していません。5件とも再現可能な問題として修正しました。修正はmainへ反映しています。公開済みv0.9.0配布ZIPの差替え・新規リリースは行っていません。

| 修正順 | 問題と変更 |
|---|---|
| ① 保存互換性 | 画像書出し・設定・作品保存/読込・自動保存で品質1〜100を統一。旧品質5の作品も、値を捨てずに読み込めます。自動保存OFFでも保存可能です。 |
| ② ペイント | 描画は元の画像へ行い、表示用マスク・色付けを1回だけ適用。連続ストロークで半透明部分が薄くならず、プレビューと確定結果が一致します。 |
| ② 加工情報 | 背景削除や描画の後は古い調整の元画像を再編集用として使いません。過去の設定を来歴として残し、新しい調整は現在の画像から開始。検証可能な調整結果には画像の識別子を記録します。 |
| ③ プレビュー | 未確定の調整・描画はレイヤーID単位。元画像が同じ複製レイヤーでも、片方のプレビューが他方へ波及しません。 |
| ④ 不在ジョブ | 通常生成・漫画・AI効果文字などの監視で共通判定を使用。キュー/ComfyUI履歴の不在を15秒以上・3回以上確認し、保存済み結果と再照合して終了状態へ移します。通信障害は不在の根拠にせず、全体停止要求も送りません。完了と競合した場合はサーバー側でも完了候補を保護します。 |
