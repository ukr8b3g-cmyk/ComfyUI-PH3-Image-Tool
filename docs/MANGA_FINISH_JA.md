# 白黒漫画仕上げ（manga.1）

MangaScreenの線分離・線を除いた明暗推定・4段階の面整理・グラデーション・45度網点・ベタ内の白抜きを使用します。元実装とMIT表示はパッケージ内に保持しています。既存の漫画変換と背景削除も引き続き使えます。

## 操作

1. レイヤー一覧で画像を選び、「白黒漫画仕上げ」を開きます。
2. 網点、白点、黒点、トーン濃度を設定して「プレビューを更新」。処理前後は透明・白・黒・緑の背景で比較できます。
3. 「レイヤー分離して採用」で白地／トーン／線画・ベタ／白抜きの4枚を追加します。元画像は削除せず非表示で残し、文字と吹き出しはそのままです。「元に戻す」も使えます。
4. PH3を使う場合は同じ画面の「PH3で漫画化して仕上げ」。現在設定されているモデル・Sampler・Sigma・Seed・参照画像を使い、選択した画像だけを送ります。通常の指示文は書き換えません。結果は自動採用せず、候補の「レイヤーに採用」で追加します。
5. 仕上げ済みレイヤーを選んで再度開くと、保存してある仕上げ前の画像から再計算できます。新しい結果の採用時は、前の仕上げ一式を非表示で保持します。一式の中にロックしたレイヤーがある場合は、先に解除してください。
6. 「保存・ノードへ適用」で編集状態と合成を保存。「画像書出し」でPNG／WebP／JPEGを出力します。透明を残すときはPNGまたはWebPで「透過を維持」を有効にします。「プロジェクト書出し」は元画像と各レイヤーを含む編集用形式です。

## 透明度と網点

- 背景の自動削除とは別機能です。必要なら既存の「背景削除」またはレイヤーマスクを先に使用してください。PH3はRGBを生成し、この機能が入力画像のアルファを保持・再適用します。生成で輪郭が変わるとアルファとのずれが生じる場合があります。
- 白い肌・服と背景の透明を区別します。4枚の各画素は重複させず、全枚数を通常合成したとき半透明のアルファも元画像と一致します。白地は白い領域を持ち、線画等の下を全面的に埋める下敷きではありません。そのため部品を非表示にすると、その領域は透明になります。
- 網点は採用時のキャンバス原寸・同じ原点で作ります。小さい画像は1網点5px以上になるよう実効網点数を制限します。画面の縮小表示と原寸画像の見え方は異なります。
- 採用後は通常の画像レイヤーです。移動・回転・拡縮だけでは網点を自動再生成しません。再仕上げするか、配置を確定してから仕上げてください。複数部品は対応する位置をそろえて扱ってください。
- 外部Manga Lineartモデルは必須にしていません。今回の線分離はMangaScreen内蔵処理です。紙色・インク質感・コマの自動クロップは適用せず、既存の背景・フレーム・吹き出し機能を保持します。

## 環境

既存のOpenCVとNumPyを使います。未導入環境では理由を表示し、この機能だけを無効にします。モデルや依存パッケージを自動取得しません。ComfyUI_WではOpenCV 4.13.0.92、NumPy 2.5.4を確認済みです。コード反映後はComfyUIの再起動とブラウザーの再読み込みが必要です。

## 検証範囲

CPUで元実装との画素一致、網点の帯状分割の継ぎ目、半透明の再合成、元画像保持、API、保存形式、透過PNG／WebPのメモリー内エンコードを検証。Windows隔離ブラウザーで日英画面、プレビュー、4レイヤー採用、保存・再読込、模擬PH3候補の明示採用を確認しました。

実PH3のGPU推論・漫画化品質・実ComfyUI再起動は未確認です。ブラウザーからのダウンロードは許可されず、実ファイル保存の確認は行っていません。描画・エンコードの検証と区別します。
